# LogHunterAI

## AI-Powered SOC Threat Detection & Log Intelligence Platform

LogHunterAI is a cybersecurity-focused log analysis platform that automatically detects suspicious activities, brute-force attacks, and security threats from system logs.

## Features

- Automated log parsing and analysis
- Brute-force attack detection
- Suspicious IP identification
- Severity classification (Critical, High, Medium, Low)
- AI-powered security recommendations
- Interactive Streamlit dashboard
- Security report generation

## Technologies Used

- Python
- Streamlit
- Pandas
- Machine Learning
- Cybersecurity Log Analysis

## Project Workflow

1. Upload log files
2. Parse and analyze logs
3. Detect suspicious activities
4. Classify threat severity
5. Generate AI recommendations
6. Display results in dashboard

## Sample Threats Detected

- Brute Force Attacks
- Repeated Failed Login Attempts
- Suspicious Source IPs
- SSH Authentication Failures
